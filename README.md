# SEJURE — prototipo Flutter

Prototipo móvil funcional para consultar y seguir remates judiciales en Colombia.

## Ejecutar

1. Instala Flutter desde la documentación oficial.
2. Abre una terminal en esta carpeta.
3. Si aún no existen las carpetas nativas, créalas sin reemplazar `lib/main.dart`:

   ```bash
   flutter create --platforms=android,ios .
   ```

4. Instala dependencias y ejecuta:

   ```bash
   flutter pub get
   flutter run
   ```

No se utilizan paquetes de terceros. Las imágenes de demostración se cargan desde
Unsplash, por lo que requieren conexión a internet.
